## 📋 Sobre o Projeto

O **Move Speed APP** é um velocímetro digital para atividades físicas. Ele utiliza a Geolocation API do navegador para obter a velocidade atual do usuário em tempo real.

### Funcionalidades:

- Exibição da velocidade atual em **Km/h**
- Botões **Start** e **Stop** para iniciar/parar a medição
- Interface limpa e focada em mobile
- Uso da API nativa de geolocalização do navegador

## 🚀 Como rodar localmente

1. Clone o repositório:
```bash
git clone https://github.com/Marcosmto/moveSpeedAPP.git
```

2. Abra o arquivo `HTML/speedmeter.html` no navegador (preferencialmente no celular)

3. Permita o acesso à localização quando solicitado
